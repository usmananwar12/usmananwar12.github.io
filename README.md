# usmananwar.me

Personal site of Usman Anwar. Built with [Astro](https://astro.build), deployed to GitHub Pages.

## Develop

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # static output in dist/
npm run check     # type-check
```
     
Requires Node 22.12+ (CI uses Node 24).

## Editing content

All content lives in `src/data/`, so there's no need to touch components for routine updates.

| File | What it controls |
| --- | --- |
| `src/data/site.ts` | Name, SEO description, social links, email |
| `src/data/experience.ts` | Roles and responsibilities |
| `src/data/projects.ts` | Selected work |
| `src/data/stack.ts` | Tech stack and proficiency tiers |
| `src/data/research.ts` | Security focus areas, audit contests, tools & experiments |

Values prefixed with `TODO:` are placeholders. `npm run build` prints a warning for each one still left, and
`npm run dev` outlines them in yellow on the page.

### Publishing a security writeup

1. Copy `src/content/research/_template.md` to `src/content/research/<slug>.md`.
2. Fill in the frontmatter and set `draft: false`.
3. It appears in the Security Research section and at `/research/<slug>`.

### Regenerating images

`public/og.png`, `public/apple-touch-icon.png` and `public/favicon.ico` are generated by `npm run og`
(edit `scripts/generate-og.mjs` to change the text).

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds and deploys to GitHub Pages.

One-time setup: in the repo's **Settings → Pages**, set **Source** to **GitHub Actions** and confirm the custom
domain is `usmananwar.me`. `public/CNAME` ships the domain with every build.
